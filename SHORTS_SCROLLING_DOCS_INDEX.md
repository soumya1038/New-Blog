## 🎯 Key Concepts

### The Three Pillars
1. **CSS Scroll-Snap** - Handles all scroll physics
2. **IntersectionObserver** - Tracks visible video
3. **Minimal JavaScript** - Only updates state

### The Golden Rule
**Let the browser do what it does best. JavaScript should observe and react, not control.**
